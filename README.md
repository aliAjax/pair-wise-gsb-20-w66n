# hxwl-06 显微镜玻片观察 · 课堂讲评台

样本、多倍率视野与染色观察记录库，支持实验课投屏逐条讲评。

## 技术栈

React + Vite + TypeScript + CSS（localStorage 持久化，无后端）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5106

## 课堂讲评功能

- **创建课堂**：从已有观察记录中挑选样本，↑↓ 调整展示顺序；可复用历史课堂的样本顺序。
- **投屏讲评**：大字突出当前样本、放大倍数与观察结论，进度条/队列显示讲评位置；支持全屏（F）与键盘 ← → 切换。
- **复看请求**：学生对当前样本发起复看请求；当前样本存在未处理请求时，老师不能切到下一条或跳转，必须先「复看」或「驳回」。
- **请求跟随原样本**：请求按样本记录保存，切走再切回仍挂在原样本上；课堂结束后历史记录里仍可查。
- **讲评只读**：讲评期间记录库只读；确需更正必须结束课堂并填写更正原因，下一次课堂使用更正后的新内容。
- **重开恢复**：课堂顺序、当前讲评位置、复看请求（含未处理项）都保存在浏览器，重开页面自动恢复。

## 数据存储

- `hxwl06.records.v1`：观察记录（首次打开内置 8 条示例）
- `hxwl06.sessions.v1`：课堂与讲评队列顺序
- `hxwl06.requests.v1`：复看请求（按 recordId 关联原样本）
- `hxwl06.activeSessionId.v1`：进行中的课堂
