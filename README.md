# hxwl-06 显微镜玻片观察

样本、多倍率视野与染色观察记录库 · 课堂讲评台

## 技术栈

React + Vite + TypeScript + CSS（本地 localStorage 持久化，无后端）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5106

## 功能

### 记录库
- 9 条预置观察记录（样本名称、类型、染色方式、放大倍数、观察结构、视野描述、**结论**）
- 按类型筛选与关键词搜索；教师可新增记录

### 课堂讲评台
1. **创建课堂**：从已有记录中勾选样本，上下移动排好展示顺序，命名后开始投屏讲评。
2. **投屏讲评**：当前样本在顺序条中高亮；主画面突出**当前样本、放大倍数、结论**；支持上一条/下一条与 ← → 方向键，可点回看过往样本。
3. **复看请求**：学生视角对当前样本发送带姓名和原因的复看请求；请求**始终挂在原样本上**，顺序条与侧栏均显示待处理数。
4. **处理门禁**：当前样本存在未处理请求时，「下一条」禁用，教师必须逐条确认处理（可写处理说明）后才能推进；回看过往样本时请求仍在。
5. **讲评只读**：课堂进行期间记录只读，不能新增；确需更正必须结束课堂并**填写原因**（含快捷原因），结束后记录解除只读，下一次课堂用更正后的新内容创建。
6. **历史存档**：已结束课堂保留名称、起止时间、结束原因、样本顺序及每条请求（含未处理项）。
7. **持久化**：刷新/重开页面后，进行中的课堂、展示顺序、当前位置与未处理请求全部恢复（localStorage）。
